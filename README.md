# React Best Practices Web

## Overview
This project is a category-driven web guide to React best practices, based on the React Best Practices published by Vercel. 
Each category explains key performance and architecture topics, and each rule page provides a concise description with examples and impact.

## Highlights
- Category-based navigation for quick discovery
- Rule pages with descriptions, code examples, and impact
- Multi-language support
- Light/Dark theme support


This site is intended to use the domain [study-react](study-react.com)_
